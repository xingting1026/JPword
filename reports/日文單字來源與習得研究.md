# 以開放辭典與提取練習打造日文單字儲備站

**結論先行（BLUF）**：一個放在 GitHub Pages 上、資料全部打包成靜態檔的日文單字網站，在法律與技術上完全可行，但資料層必須以 EDRDG 的 **JMdict（CC BY-SA 4.0，約 218,863 筆詞條）** 為骨幹，透過 scriptin/jmdict-simplified 的週更 JSON 取得乾淨結構，再用 **OpenJLPT（CC BY-SA 4.0）** 補 JLPT 等級、**Jiten.moe 或 Kanjium（皆 CC BY-SA 4.0）** 補頻率、**Kanjium accents.txt（124,137 詞）** 補音調，而中文釋義目前唯一可合法重散布的大型來源是 **kaikki.org 的中文版 Wiktionary 日語抽取檔**（約 7–9 萬義項，繁簡混雜，需 OpenCC 轉換）；音檔則沒有任何開放的詞級資料集，實務上只能用瀏覽器 Web Speech API 或離線用 VOICEVOX 預先產生。jpdb、Kanshudo、iKnow Core、NHK 音調辭典轉檔皆為專有或爬取資料，不可打包。學習科學方面，證據最強的三條規則是：**間隔重複（分散學習回憶率 47% 對集中學習 37%）、每次曝光都要是提取練習而非重看（答對後再重看對一週後記憶「毫無」增益）、答錯後立刻顯示正解（一週後保留率提升 494%）**；「每天幾個新字」沒有實證答案，只有 Anki 以工作量推得的「新字 ≈ 複習量 ÷ 10」；有限單字池有詞彙覆蓋率研究背書（日文 95% 覆蓋需約 9,446 個詞彙素），無限池則無任何文獻支持；「隨機」應只用於決定「到期集合內的順序」，不能跨整個池子純隨機抽；背景音樂預設關閉（有歌詞最傷，純音樂效果在直接重複實驗中消失）；音檔預設開啟。對台灣學習者最關鍵的設計含意是：前 2 萬高頻詞中約 30% 是 **日中同形同義語**，看字即懂，因此 **考「讀音」而不是考「意思」**；約 5% 是 **同形類義／異義語（要注意語）** 需明確標示「中文≠日文」；**和語與外來語** 才是真正的瓶頸，須加重複習權重；母語為華語者對音調有近乎母語的辨識力，所以顯示音調標記值得；促音、長音的錯誤會直接出現在假名拼寫上，所以用打字回想而非選擇題。最可行的技術方案是 Vite + TypeScript、`ts-fsrs`（FSRS-6，MIT）排程、以「1 − 可提取率」加權的無放回隨機抽樣、localStorage 加 JSON 匯出、`wanakana` 做羅馬字轉假名輸入、`lang="ja"` 加 Noto Sans JP 處理字形。

## 一、JMdict 是唯一可靠骨幹，其餘欄位靠五個補丁拼出來

沒有任何單一開放資料集同時具備漢字、假名讀音、中文釋義、頻率、JLPT 等級、音檔與音調；每一個欄位都要從不同來源接合，而每個來源的授權條件又不同。研究日期為 2026-10-07，所有標註「實測」的檔案大小均在當日以 HTTP HEAD 或下載取得。

**骨幹：JMdict / jmdict-simplified。** EDRDG 的 JMdict 每日重建，2026-10-05 的英文 JSON 建置含 **218,863 筆詞條**（實測），JMdict_e.gz 為 10.6 MB、JMdict.gz 為 22.2 MB ([EDRDG](https://www.edrdg.org/wiki/JMdict-EDICT_Dictionary_Project.html); [jmdict-simplified releases](https://github.com/scriptin/jmdict-simplified/releases/latest))。釋義語言包含英、德、俄、匈、西、荷、瑞典、法、斯洛維尼亞，**明確不含中文**；也沒有音調、音檔、JLPT 等級 ([EDRDG](https://www.edrdg.org/wiki/JMdict-EDICT_Dictionary_Project.html))。直接解析 XML 會遇到 150 多個 DTD 實體（&n;、&v5r;、&uk; 等），所以實務上應改用 scriptin/jmdict-simplified 的 JSON：每週一自動發布，`jmdict-eng-common` 僅 **1.4 MB（壓縮）／22,644 詞**，`jmdict-eng` 全量 11.5 MB／118 MB 解壓 ([README](https://raw.githubusercontent.com/scriptin/jmdict-simplified/master/README.md))。JSON 的 `common` 布林值定義為「含 news1、ichi1、spec1、spec2、gai1 任一標記」，它只是一個子集合，**不是排名**；EDRDG 自己也承認「有些標為常用的詞其實不太常用」 ([EDRDG](https://www.edrdg.org/wiki/JMdict-EDICT_Dictionary_Project.html))。對建站特別有用的欄位：`languageSource`（外來語來源語，6,226 筆）可直接切出片假名外來語類別；`uk`（通常只寫假名，9,603 筆）決定該以假名當標頭；`sK`/`sk`/`rK` 標記（分別 15,629、5,076、5,886 筆）是搜尋用或罕見寫法，應對學習者隱藏；常用子集中 **3,626 筆有多個假名讀音、4,462 筆沒有漢字形**（實測） ([release assets](https://github.com/scriptin/jmdict-simplified/releases/latest))。

**EDRDG 授權的三個實務義務。** 授權為 CC BY-SA 4.0 且「對商業使用沒有任何限制」，但附加條件：網頁型辭典「必須在每一個畫面顯示致謝」（例如頁尾文字）、「必須有定期從最新版本更新資料的程序」、不得對資料主張著作權，衍生作品須以相同或相容授權散布 ([EDRDG licence](https://www.edrdg.org/edrdg/licence.html))。這意味著網站的資料層必須以 CC BY-SA 4.0 公開，且應設定 GitHub Actions 定時拉取 jmdict-simplified 最新版本以滿足「定期更新」。

**JLPT 等級：官方不存在，只有社群近似。** JLPT 官方明言不公布單字表，理由是「學習日語的終極目標是用語言溝通而非背誦」 ([JLPT FAQ](https://www.jlpt.jp/e/faq/index.html))。Jisho.org 等所有工具使用的等級都來自 Jonathan Waller（tanos.co.uk）的 CC BY 清單 ([jisho.org/about](https://jisho.org/about))，但該站已失效（本次 DNS 查詢失敗，CC BY 聲明僅見於鏡像引用）。最乾淨的重新包裝是 **evanclan/OpenJLPT**（CC BY-SA 4.0，含 NOTICE）：以 Waller 等級為基礎、詞義取自 JMdict、漢字取自 KANJIDIC2、例句取自 Tatoeba，提供 JSON／CSV／SQLite；各級數量 N5 674、N4 630、N3 1,659、N2 1,778、N1 3,070，合計 7,811 ([OpenJLPT](https://github.com/evanclan/OpenJLPT))。**【未解決矛盾】** PyPI 頁面卻稱 8,334 詞、2,211 漢字，與 README 的 7,811 不符 ([PyPI](https://pypi.org/project/openjlpt/))。另需注意 KANJIDIC2 的 JLPT 欄位是 **2010 年改制前的四級制**，不能直接當 N1–N5 用 ([KANJIDIC Project](https://www.edrdg.org/wiki/KANJIDIC_Project.html))。

**頻率：Jiten.moe 與 Kanjium 授權最乾淨，BCCWJ 法律模糊，jpdb 不可用。** Jiten.moe 以 16,924 部作品、34 億字元的語料提供 12 類（全域、動畫、小說、YouTube 等）頻率表，CSV 與 Yomitan 格式皆有，授權 CC BY-SA 4.0 ([jiten.moe](https://jiten.moe/frequency-dictionaries))。Kanjium 倉庫同時含 wikipedia_freq.txt（20,001 行）與 novels_freq.txt（285,719 行），CC BY-SA 4.0，最後提交 2026-10-03 ([kanjium](https://github.com/mifunetoshiro/kanjium))。NINJAL 的 BCCWJ 頻率表最具權威，但頁面只說「研究、教育目的であれば無償で自由にお使いになれます」，**沒有明文授予重新散布或商業使用** ([BCCWJ freq-list](https://clrd.ninjal.ac.jp/bccwj/freq-list.html))；**【未驗證】** 搜尋摘要稱 BCCWJ 報紙統計不得商用，但未取得原始網址。jpdb 衍生清單（MarvNC、Kuuuube）是「從 JPDB 語料爬取」且未標授權，MarvNC 版已停止維護 ([Kuuuube](https://github.com/Kuuuube/yomitan-dictionaries); [MarvNC](https://github.com/MarvNC/jpdb-freq-list))。語料偏向也要注意：jpdb 以輕小說、視覺小說、動畫為主，正式詞如「審議会」在 CC100 排 9,733、在 JPDB 卻排 58,730 ([jiten.moe/other](https://jiten.moe/other))；對一般目標的台灣成人學習者，混合 Jiten.moe 全域榜與 Wikipedia 2 萬榜比單用 jpdb 平衡。**【推論】** Kanjium 的 novels_freq.txt（「5,000 本小說」）很可能就是流傳的 Innocent Corpus，若屬實則透過 Kanjium 可以 CC BY-SA 4.0 取得；兩個專案都未確認此事。

**中文釋義：只有中文版 Wiktionary 一條路。** 搜遍 GitHub 的繁中 JLPT 單字 JSON 只找到英文釋義倉庫；Weblio、小學館、白水社的日中辭典均為商業服務；NICT 的 EDR 日中辭典限「非営利目的での使用」且禁止未經許可再散布 ([EDR](https://www2.nict.go.jp/ipp/EDR/ENG/E-Guide/Guide_Ae.html))。唯一可行的是 kaikki.org 的中文版 Wiktionary 抽取：日語條目分為「日語」（70,959 義項、89.9 MB JSONL）與「日语」（93,376 義項、36.2 MB）兩個名稱，CC BY-SA／GFDL，每次 dump 重建 ([kaikki zhwiktionary](https://kaikki.org/zhwiktionary/index.html))。實測樣本（英語）顯示記錄含 `ruby` 振假名配對、`sounds` 內的東京音調標籤（Heiban）與羅馬字音調記法，是意外的第二個音調來源。**實務陷阱**：釋義繁簡混雜（未量化），建置時必須經 OpenCC s2twp 轉換；且以（漢字形、假名讀音）與 JMdict 接合後，仍會有大量常用詞沒有中文釋義，需退回英文釋義或在建置期離線機器翻譯並明確標示。Tatoeba 的日中句對只有 **16,218 條連結、14,990 個不同日文句**，中文語料本身繁簡混用（抽樣字元測試：18,375 行含繁體、20,474 行含簡體），相比之下日英連結有 280,716 條 ([Tatoeba exports](https://downloads.tatoeba.org/exports/per_language/jpn/))。Tanaka 語料來源的例句含學生輸入錯誤與過度直譯，EDRDG 自己「不建議做統計分析」；JMdict_e_examp 內嵌的約 31,400 句（對應 28,700 詞條）是較安全的子集 ([Tanaka Corpus](https://www.edrdg.org/wiki/Tanaka_Corpus.html))。

**音調：Kanjium 是唯一清楚開放的資料。** accents.txt 含 124,137 詞，格式為「標頭 \t 假名 \t 音調位置（逗號分隔，可多個）」，例如 `１０月\tじゅうがつ\t4,0`，CC BY-SA 4.0 ([accents.txt](https://raw.githubusercontent.com/mifunetoshiro/kanjium/master/data/source_files/raw/accents.txt))；Yomichan 的音調就是從這裡來的 ([Yomichan commit](https://git.foosoft.net/alex/yomichan/commit/d792d89f6d4c8c86082b446ad0e2d64aca668e20))。流傳的 NHK2016、大辞林音調辭典是版權作品的非官方轉檔，Wadoku 為非商業授權，都不能打包 ([MarvNC](https://github.com/MarvNC/yomitan-dictionaries))。接合時要按「每個讀音」對應，因為 JMdict 一詞多讀、Kanjium 一讀多調。**【缺口】** Kanjium 與 JMdict 常用子集的覆蓋重疊率未量化。

**音檔：沒有開放的詞級資料集，靜態站只剩三條路。** JapanesePod101 的音檔「專供 EDICT 與 JapanesePod101 使用，目前不開放」 ([EDRDG list](https://www.edrdg.org/jmdict_edict_list/2014/msg00068.html))；Forvo API 非營利方案每月 2 美元、每日 500 次且「不得商用」，而且金鑰在靜態站上必然外洩 ([api.forvo.com](https://api.forvo.com/))；Tatoeba 日文音檔只有 6,332 個不同句子，其中 5,111 筆未標授權、1,282 筆 CC BY-NC，僅 27 筆 CC BY（實測） ([Tatoeba downloads](https://tatoeba.org/en/downloads))。可行方案一是 **Web Speech API**：零成本、不需金鑰，Chrome／Firefox／Safari／Edge 皆支援 `ja-JP` 語音 ([MDN](https://developer.mozilla.org/docs/Web/API/Web_Speech_API))；方案二是 **VOICEVOX** 離線預產：生成音檔「商用・非商用問わず利用することができます」，但「需要標示使用了 VOICEVOX 的信用」且各角色語音庫另有條款 ([VOICEVOX terms](https://voicevox.hiroshiba.jp/term/))——**【推論】** 6,000 詞 × 30–50 KB ≈ 200–300 MB，接近 GitHub Pages 1 GB 軟上限的三成，宜另外託管。

## 二、間隔與提取是效果來源，「每天幾個字」只能用工作量推算

**間隔效應強健，但「漸擴」並不比「等距」好。** Cepeda 等人 2006 年對 317 個實驗、839 次評估的統合分析顯示，分散練習的回憶率 **47%** 對集中練習 **37%**，且最佳間隔隨保留期拉長而增加 ([Cepeda et al. 2006](https://pubmed.ncbi.nlm.nih.gov/16719566/))。2008 年超過 1,350 人、保留期長達一年的實驗給出可操作的比例：最佳複習間隔約為目標保留期的 **10–20%（數週目標）**，降到 **5–10%（一年目標）** ([Cepeda et al. 2008](https://pubmed.ncbi.nlm.nih.gov/19076480/))——換算成規則：想記住一個月，關鍵複習間隔約 3–6 天；想記一年，約 2–4 週。第二語言專屬的 Kim & Webb 2022 統合分析（48 個實驗、N = 3,411）確認間隔效應為「中到大」，較短間隔在立即測驗等效但在延遲測驗較差，而且 **等距與漸擴間隔在統計上等效** ([Kim & Webb 2022](https://pressto.amu.edu.pl/index.php/ssllt/article/view/49487))。Nakata 2015 在控制總間隔後只在寬鬆計分下看到漸擴 +4.6% 的小優勢，嚴格計分無差異 ([Nakata 2015](https://sanad.iau.ir/en/Article/897069))；Karpicke & Roediger 2007 更指出真正的有效成分是 **延後第一次測驗讓它費力**，之後間隔如何擴張對長期記憶幾乎無影響 ([Karpicke & Roediger 2007](https://profiles.wustl.edu/en/publications/expanding-retrieval-practice-promotes-short-term-retention-but-eq/))。因此 SM-2／FSRS 式的漸擴排程是可辯護的，但網站不應宣稱「漸擴本身經科學證明最佳」。**【單一研究、方向相反】** Rogers & Cheung 2020 在香港小學課堂中發現 1 天間隔勝過 8 天，提醒初次接觸的新詞第一個間隔應短（當天或隔天）再逐步拉長 ([Rogers & Cheung 2020](https://repository.eduhk.hk/en/publications/input-spacing-and-the-learning-of-l2-vocabulary-in-a-classroom-co/))。個人化排程有實證：Lindsey 等 2014 年讓 179 名中學生學一學期西班牙文單字，模型化個人複習比集中學習高 **16.5%**，比一體適用的間隔表高 **10.0%** ([Lindsey et al. 2014](https://home.cs.colorado.edu/~mozer/Research/Selected%20Publications/reprints/LindseyShroyerPashlerMozer2014Published.pdf))。**【缺口】** Kim & Webb 的 Hedges' g 實際值因付費牆未取得。

**提取練習是最重要的單一成分，重看已會的字毫無價值。** Karpicke & Roediger 2008 用 40 組斯瓦希里語–英語詞對做的實驗是這個領域的定錨：某個詞一旦被正確回憶過，之後「只重複看不測驗」對一週後記憶 **沒有效果**，而「只重複測驗不重看」有大幅正效果；學生對自己表現的預測與實際成績無相關 ([Karpicke & Roediger 2008](https://learninglab.psych.purdue.edu/downloads/2008/2008_Karpicke_Roediger_ScienceSupportingMaterial.pdf))。單次學習內的劑量也有答案：Nakata 2017 讓 98 名日本學生在一節課內提取 1、3、5 或 7 次，兩週後 5 與 7 次確實優於 1 與 3 次，但 **控制時間後，一次提取的每分鐘增益最大** ([Nakata 2017](https://www.cambridge.org/core/journals/studies-in-second-language-acquisition/article/does-repeated-practice-make-perfect-the-effects-of-withinsession-repeated-retrieval-on-second-language-vocabulary-learning/F14BA8A576CD2563D14CEA46E35D842E))。Rawson & Dunlosky 2011 的建議是首次學習達到 3 次正確回憶，再安排 3 次間隔很寬的再學習，其中再學習的長期效益最大 ([Rawson & Dunlosky 2011](https://www.retrievalpractice.org/archive/2018/successive-relearning))。合理預設：引入當天 1–2 次成功提取即可，其後靠跨日間隔。

**答錯後顯示正解是整個文獻中效應最大的動作。** Pashler 等 2005 年用 258 人學盧干達語–英語詞對：答錯後提供正解讓一週後保留率 **提高 494%**，而答對後的回饋無論信心高低都幾乎沒差 ([Pashler et al. 2005](https://www.yorku.ca/ncepeda/publications/PCWR2005.pdf))。Metcalfe 2017 的回顧指出避免錯誤反而讓練習變得容易且可預測，錯誤加上更正回饋能形成獨特的情節記憶；成人在即時與延遲回饋間表現相同，關鍵是學習者有沒有「注意」回饋 ([Metcalfe 2017](https://learningscientists.org/blog/tag/feedback))。**【推論】** 答錯後要求重打一次正解可確保注意力，但沒有 L2 研究直接比較「重打」與「只看」。

**目標成功率：不要引用「85% 法則」。** Wilson 等 2019 年的 85% 法則是為二元分類的梯度式學習器與知覺學習推導的，作者自述最適用於如放射科醫師辨識腫瘤一類任務，**不是** 陳述性回憶 ([Wilson et al. 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6831579))。閃卡的數字來自軟體實務：FSRS 預設目標保留率 0.9，提高時工作量「近乎指數」成長，Anki 的「最低建議保留率」計算常落在 0.80–0.85 ([Anki forums](https://forums.ankiweb.net/t/about-minimum-recommended-retention-cmrr/54501/2); [FSRS tuning guide](https://jiten.moe/guides/tuning-fsrs))——**【非同儕審查】** 這是論壇與軟體遙測，不是隨機對照試驗。值得注意的是主觀難易度是糟糕的指引：Kornell 2009 中 90% 的學生用大疊卡片學得更多，卻有 **72%** 在親身比較後仍偏好小疊 ([Kornell 2009](https://www.learningandthebrain.com/blog/flashcard-strategies/))。因此網站不應讓使用者在答對後憑「感覺很熟」縮短間隔。

**「每天幾個新字」沒有實證，有的是比例。** 文獻中沒有任何研究直接測試每日新字上限；唯一有依據的數字是 Anki 預設 20 新卡／200 複習，手冊說明新卡上限「通常應比複習上限小至少 10 倍」，這是從工作量累積觀察而來，不是對照實驗 ([Anki manual](https://docs.ankiweb.net/deck-options.html))。一次學習的集合大小本身不重要：Nakata & Webb 2016 比較 20 字整體學習與 4 字、10 字分段學習，發現「間隔對學習的影響大於整體／分段的區別」，間隔相等時集合大小無顯著差異 ([Nakata & Webb 2016](https://www.cambridge.org/core/journals/studies-in-second-language-acquisition/article/does-studying-vocabulary-in-smaller-sets-increase-learning/E17B75ABAE1300734AF014C363D59FBC))；Kornell 2009 中 1 疊 20 張勝過 4 疊 5 張（65% 對 38%），機制正是大疊拉長了同一張卡的重複間隔。要避免的是 4–5 張的小疊反覆操練，20 張以上的集合完全沒問題。

**有限單字池有覆蓋率研究背書，無限池沒有。** 詞彙覆蓋率研究本質上就是在談「有限的頻率帶」：Nation 2006 估計英文要達到無輔助閱讀所需的 98% 覆蓋需 8,000–9,000 詞族 ([Nation 2006](https://www.wgtn.ac.nz/__data/assets/pdf_file/0018/1626120/2006-How-large-a-vocab.pdf))。日文方面，松下達彥的 VDRJ（以 BCCWJ 3,300 萬詞建置）顯示 **95% 覆蓋需要前 9,446 個語彙素（lemma），98% 需要 20,000–24,000 個**，遠高於英文 ([松下 2018 NINJAL](https://www2.ninjal.ac.jp/jll/lsaj/wp-content/uploads/2015/07/869b469213df7c0f6deaad728b97a6b9.pdf))；松下 2014 另主張有辭典輔助時 93% 即可 ([Kramer 2023](https://jalt-publications.org/content/index.php/jer/article/view/1221))。松下的通用學習者單字表分為 2,000／4,000／6,000／8,000／10,000 五級，覆蓋率在母語者文本與學習者文本、口語與書面都高 ([JALT JER](https://jalt-publications.org/content/index.php/jer/article/view/1221))。**【非同儕審查摘要】** NINJAL 公開活動資料給出粗略對應：基礎（N5/N4）約 1,500–2,000 詞、中級（N3/N2）約 7,000、高級（N1）18,000 以上 ([NINJAL openhouse 2022](https://www2.ninjal.ac.jp/openhouse/2022/pdf/23.pdf))。結論很清楚：以頻率排序的 5,000–10,000 詞有限池、搭配 93%／95%／98% 的里程碑，是有文獻基礎的設計；覆蓋曲線在一萬詞後急劇趨平，每多一詞的邊際價值遞減，無限池沒有任何文獻支持。**【缺口】** 松下的日文覆蓋曲線逐點數值未取得；一則搜尋摘要稱「一萬詞約 86% 覆蓋」但無法驗證，故不列為發現。

**隨機呈現：有理論依據，但沒有直接的 L2 實驗。** 沒有任何對照研究在控制間隔後單獨比較「隨機 vs 固定順序」——**【缺口】**。間接證據一致指向隨機：序列位置效應讓固定清單的首尾項目被多練、中間項目被遺忘 ([Macmillan](https://digfir-published.macmillanusa.com/cogtk2/serial_position_effect.html))；Nakata 2008 讓 226 名日本高中生學英文單字，固定順序的「單字表」組在延遲測驗表現最差，電腦排程組最好 ([Nakata 2008](https://www.cambridge.org/core/journals/recall/article/english-vocabulary-learning-with-word-lists-word-cards-and-computers-implications-from-cognitive-psychology-research-for-optimal-spaced-learning/4742121ED692165551C531F6464E67FA))。但「隨機」有一個重要界線：**跨整個池子純隨機抽樣會破壞間隔**（有些字太常出現、有些字太久不出現），正確做法是由間隔模型決定「哪些字到期」，再對到期集合洗牌。語義叢集則要避免：Nakata & Suzuki 2019 讓 133 名日本大學生學 48 組英日詞對，一週後四個條件的成績是相關集中 17.74%、相關間隔 24.15%、無關集中 15.99%、**無關間隔 29.09%**，相關詞彙的集合內混淆錯誤（集中 6.32%、間隔 3.70%）遠高於無關詞（0.47%） ([Nakata & Suzuki 2019](https://www.cambridge.org/core/journals/studies-in-second-language-acquisition/article/effects-of-massing-and-spacing-on-the-learning-of-semantically-related-and-unrelated-words/F58BA8D70385603B9C42E408BFCB8A10))。Tinkham 1993 與 Waring 1997 的早期研究發現語義相關集合需要更多次嘗試才能學會，但 **【有爭議】** 一篇 2022 年回顧指出有四項近期研究反而發現語義叢集得分較高 ([Frontiers 2022](https://frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2022.997951/full))；領域共識是「結果混雜但傾向反對語義集合」，而隨機混合無關詞正是安全預設。

**方向與睡眠。** Webb 2009 顯示 L2→L1 練習建立辨識、L1→L2 練習建立產出，交叉遷移有限 ([Webb 2009](https://ir.wgtn.ac.nz/handle/123456789/23701?show=full))；Schneider 等 2002 發現 L1→L2 方向在訓練時較難、但一週後遺忘較少 ([Schneider et al. 2002](https://experts.colorado.edu/display/pubid_52638))——**【缺口】** 原文數值因付費牆未取得。Mazza 等 2016 讓 40 人分兩次學習、相隔 12 小時：中間有睡眠的組別 **再學習所需次數減半，一週與六個月後保留更好** ([Mazza et al. 2016](https://www.psychologicalscience.org/journals/psychological-science/0956797616659930/))；Dumay & Gaskell 2007 顯示新的口語詞形要經過睡眠才開始與相似已知詞產生詞彙競爭 ([Dumay & Gaskell 2007](https://eprints.whiterose.ac.uk/7437))。**【細微爭議】** Lindsay & Gaskell 顯示某些訓練方式下不睡也能整合，故睡眠是強但非必要的路徑。對應規則：新字安排在傍晚、首次複習排在隔天早上。

## 三、關掉音樂、打開音檔、先選擇後打字，每種互動方式都有對應證據

**背景音樂：預設關閉，有歌詞的最傷。** Vasilev 等 2018 年的貝氏統合分析（65 項研究）顯示噪音、語音、音樂對閱讀都有「小但可靠的負面效應」，其中 **可理解的語音與有歌詞的音樂干擾最大**，整體音樂效應約 g = –0.19 ([Vasilev et al. 2018](https://eprints.bournemouth.ac.uk/29995/); [Journal of Cognition](https://journalofcognition.org/articles/273))。Perham & Currie 2014 的閱讀理解分數：安靜 61%、無歌詞音樂 55%、有歌詞音樂 **38%**（喜歡或不喜歡都一樣） ([Learning and the Brain](https://learningandthebrain.com/blog/but-i-study-much-better-with-my-music-on))。外語單字專屬的證據更關鍵：de Groot 2006 曾報告巴哈協奏曲背景下學得較多，但 Küssner 等 2016 用 **完全相同的 64 組詞對與同一段音樂** 直接重複，合併 69 人的結果是音樂無效（F(1,68) = 0.74, p = .392），作者甚至問「尋找背景音樂對單字學習的效應是否是個紅鯡魚」 ([Küssner et al. 2016](https://pmc.ncbi.nlm.nih.gov/articles/PMC4990275/))。de Groot & Smedinga 2014 進一步發現 **熟悉語言（荷語）歌詞** 在學習當下與立即測驗損害成績，不熟悉語言（希臘語）歌詞則否；一週後差異消失 ([de Groot & Smedinga 2014](https://www.cambridge.org/core/journals/studies-in-second-language-acquisition/article/let-the-music-play/C28D533232A39482804924C26DF247DF))。Lehmann & Seufert 2017 顯示工作記憶容量最低的學習者在安靜環境比在流行歌背景下理解分數高 36.7 分（d = 2.64），高容量者不受影響，作者建議一律不用背景音樂 ([Lehmann & Seufert 2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC5671572/))。對台灣使用者的推論：華語或英語歌詞是最壞情況；日語歌詞在初學階段等同「不熟悉語言」不致傷害，但隨程度提高會變成「熟悉語言」開始干擾。唯一與「音樂」相關的正面證據是 Ludke 等 2014 讓受試者 **主動唱出** 匈牙利語片語，產出成績約為口說組兩倍 ([Ludke et al. 2014](https://ferreiralab.faculty.ucdavis.edu/wp-content/uploads/sites/222/2015/05/Ludke-et-al.-2014_SingingForeignLanguage_Mem-Cog.pdf))——那是編碼任務，不是環境音。**【缺口】** 沒有任何研究測試「目標語背景歌曲」在明示單字學習中的效果。

**例句：第一次曝光用乾淨的詞對，例句留給後續複習。** Laufer & Shmueli 1997 指出豐富語境「可能把注意力從目標詞移向其他詞或整體訊息」，孤立詞或短句的學習效果不比精緻文本差 ([Laufer & Shmueli 1997](https://journals.muni.cz/casalc-review/article/download/14192/11864))；Prince 1996 發現法語學生透過 L1 翻譯比透過 L2 句子語境學得更多，程度弱者尤其如此 ([Prince 1996](https://api.equinoxpub.com/articles/34212))。Barcroft 的 TOPRA 模型解釋原因：處理資源有限，要求「用新詞造句」這種語義加工會「大幅降低」詞形學習 ([Barcroft lab](https://sites.wustl.edu/barcroft/?p=461))。日文的詞形負擔（漢字 + 讀音 + 音調）特別重，這個警告適用得更強。語境的價值在深度：Webb 2007 讓 121 名日本大學生接觸 1、3、7、10 次語境，拼寫、意義、語法功能、搭配等各面向知識都隨次數增加 ([Webb 2007](https://d.lib.msu.edu/etd/3113/OBJ/download))。**【統合分析】** 僅靠語境的附帶學習很慢：24 項研究、2,771 人的統合顯示意義導向輸入立即只學到 9–18% 的目標詞、延遲 6–17% ([Webb et al. 2023](https://api.semanticscholar.org/graph/v1/paper/search?query=sleep+consolidation+second+language+vocabulary+learning+foreign+words&fields=title,year,venue,abstract,externalIds&limit=5))。

**圖片：只給具體名詞，而且不能讓它成為自評依據。** Plass 等 1998 年發現同時選擇文字與圖像註解的德語學習者記住更多翻譯 ([Plass et al. 1998](https://fis.leuphana.de/en/publications/supporting-visual-and-verbal-learning-preferences-in-a-second-lan/))，但 Carpenter & Olson 2012 的標題直接說出陷阱：「圖片有助於學外語單字嗎？只有當你認為它們沒有幫助時」——學習者對圖片提示 **信心更高卻不多花時間** ([Carpenter & Olson 2012](https://gmwpublic.studenttheses.ub.rug.nl/445/1/Thesis_AF_Aleman.pdf))；Boers 等 2017 也發現圖片註解「可能減少對詞形的注意」 ([Boers et al. 2017](https://ir.lib.uwo.ca/edupub/99))。具體詞在 de Groot 兩項研究中各時間點都學得比抽象詞好，是圖片最安全的落點。**【缺口】** 沒有針對日文漢字／讀音與圖片的研究。

**音檔：證據單向，預設開啟。** Bisson 等人的眼動研究顯示「邊讀邊聽」同時促進音韻與字形的詞形學習及形意連結，純聽覺輸入較難，加上文字有助切分語音 ([Bisson et al.](https://pmc.ncbi.nlm.nih.gov/articles/PMC4487591))。Icht & Mama 2019 讓希伯來語者學世界語，**出聲產出** 的詞在所有保留間隔都有顯著優勢且衰退較慢 ([Icht & Mama 2019](https://cris.iucc.ac.il/en/publications/the-effect-of-vocal-production-on-vocabulary-learning-in-a-second/))。日語音調是音位性的，多模態訓練研究發現 **音高標記訓練最穩健**，對訓練過與新詞的辨識都有改善 ([Language and Cognition 2024](https://doaj.org/article/643c5707caa449fbb53752a8f14a7d2d))。在卡片翻面時自動播放 TTS、顯示音調標記、揭曉前提示「先唸出來」，是零開發成本把被動聽變成產出效應的做法。**【缺口】** 沒有研究隔離「有 TTS vs 無音檔」對日文單字保留的效應量。

**互動方式：辨識用於建立形意連結，打字回想用於拼寫與讀音，自評最弱。** Nakata 2016 讓 64 名英語母語者用四種格式學 60 組斯瓦希里語詞對，結論是「回想格式對產出性拼寫知識更有效」、「不需要拼寫知識時辨識格式更可取」（辨識同樣或更有效且省時） ([Nakata 2016](https://www.degruyterbrill.com/document/doi/10.1515/iral-2015-0022/html?lang=en))。Kang 等 2007 發現簡答練習在後續選擇題測驗上勝過選擇題練習（d = 0.41），且 **回饋對簡答有效、對選擇題無效** ([Kang et al. 2007](https://www.gwern.net/docs/spaced-repetition/2007-kang.pdf))。自評翻卡的問題在於 Kornell & Bjork 2008：學習者幾乎一律丟掉「以為會了」的卡，允許丟卡對學習有「小但一致的負面效應」 ([Kornell & Bjork 2008](https://bjorklab.psych.ucla.edu/wp-content/uploads/sites/13/2016/07/Kornell_Bjork_2008_Memory.pdf))。設計良好的選擇題也能觸發產出式提取並附帶學到錯誤選項的資訊 ([Little & Bjork](https://itlab.us/TBL/Harvesting/TBL/Multile%20Choice%20Tests%20Exonerated.pdf))。**【缺口】** 沒有研究測試假名 IME 打字作為日語提取格式；手寫 vs 打字的文獻只涉及拼音文字與 EEG 指標。台灣使用者本就習慣注音／拼音輸入法切換，實務成本是按鍵數而非概念，用應用程式內的羅馬字→假名轉換可去掉 OS 層的 IME 切換。

**遊戲化：整體有效但元件證據薄，連勝只是互動指標。** Sailer & Homner 2020 統合分析顯示遊戲化對認知結果 g = .49（高嚴謹子集中穩定）、動機 g = .36、行為 g = .25；顯著的調節因子是 **遊戲敘事** 與 **競爭結合合作**，而非積分、徽章、排行榜本身 ([Sailer & Homner 2020](https://opus.bibliothek.uni-augsburg.de/opus4/frontdoor/index/index/docId/109056))。連勝（streak）的證據全部來自 Duolingo 內部 A/B 測試（達到 10 天連勝的使用者較不易流失、超過 600 次連勝實驗），量測的是「使用者留存」而非「單字保留」，**【非同儕審查】** ([Lazyweb summary](https://lazyweb.com/research/duolingo-streak-goals-retention))；唯一的同儕審查研究發現 Duolingo 的學習成效低於行銷宣稱，但遊戲化「無疑提供了動機效益」 ([Loewen et al. 2019](https://www.cambridge.org/core/journals/recall/article/abs/mobileassisted-language-learning-a-duolingo-case-study/A4D7C8F71782A37D258C19F357DDBCBE))。對單人網站，連勝綁定「完成當日到期佇列」才有工具價值，排行榜無關，「標記為已會」的捷徑則違反 Kornell & Bjork。

## 四、台灣學習者看字即懂，所以要考的是讀音、和語與外來語

**前 2 萬高頻詞有 30% 是「內建詞彙」，5% 是假朋友。** 松下・陳・王・陳 2020 的日中對照漢字語資料庫以 VDRJ 前 20,000 詞分析：50% 為 **漢語**（漢字音讀詞），其中 70%（全體的 35%）為 **同形語**，7,074 個同形語裡 **82% 是同形同義**（全體的 29%），其餘 18%——「每 5 到 6 個同形語就有一個」——是 **同形類義** 或 **同形異義** 的「要注意語」 ([日本語教育 177](https://www.nkg.or.jp/gakkaishi/.assets/177_5abstract.pdf))。松下在 NINJAL 的發表直接說明含意：「上位2万語のうち、30％にあたる約6千語がいわゆる日中同形同義語で、5%に相当する約千語が同形類義あるいは同形異義の要注意語である。中国語母語学習者の多くは学習しなくても日中同形同義語を目で見て理解できるが、学習しなければ音で聞いても理解できない語が多い」（前 2 萬詞中約 6,000 詞是同形同義語，約 1,000 詞是要注意語；多數華語母語者不用學就能看懂同形同義語，但不學就聽不懂） ([松下 2018 NINJAL](https://www2.ninjal.ac.jp/jll/lsaj/wp-content/uploads/2015/07/869b469213df7c0f6deaad728b97a6b9.pdf))。VSTRJ-50K 對 971 人的測量證實規模：華語母語者的閱讀詞彙量平均 **超過 30,000 詞**，非漢字圈學習者 **不到 20,000**，而且華語母語者對漢語詞明顯容易、對西方來源詞相對困難 ([日本語教育 178 最佳論文摘要](https://www.nkg.or.jp/.assets/2021bestpaper_b.pdf))。分類體系來自文化庁 1978 年《中国語と対応する漢語》的 S（同義）／O（部分重疊）／D（完全不同）／N（日語獨有）四類，對應坊間的同形同義／同形類義／同形異義 ([趙・上原 2017](https://miyazaki-u.repo.nii.ac.jp/record/5272.1/files/89_jinbun-p35.pdf))。

**教材的失敗模式正是「單一中文對譯」。** 趙乾・上原徳子 2017 分析中國最通行的大學教材『新編日本語』：5,190 詞中 1,492 詞（>28%）是同形語，O 類 257 詞、D 類 131 詞，但教材只用「漢字＋ルビ＋品詞－中国語訳語」格式標一個對譯，例如「勝負（名）- 胜负」漏掉日語「比賽」義，「関心（名）- 关心」沒警告中文「关心」還有「關懷某人」義；作者結論是沒有明示對比，學習者「到中上級都難以掌握同形語」 ([趙・上原 2017](https://miyazaki-u.repo.nii.ac.jp/record/5272.1/files/89_jinbun-p35.pdf))。松下 2021 解釋機制：「漢字を見た瞬間に中国語知識は自動的に活性化する」（看到漢字的瞬間中文知識就自動活化），因此核心義或搭配不同時必須有意識地克服；隨程度提高 L2 知識才逐漸獨立於 L1（茅本 2000） ([松下 2021 JASLA](https://repository.ninjal.ac.jp/record/2000019/files/Matsushita2021_kanji-vocab-learning.pdf))。邱學瑾 2003 對台灣學習者的語義判斷實驗更直接：**同根語** 的意義直接由字形或中文音韻取得，「日語音韻沒有貢獻」；非同根語才用到日語音韻 ([邱 2003](https://hiroshima.repo.nii.ac.jp/records/2031020))。王舒茵的研究顯示中文註釋對 65 名中級華語學習者的立即與四週後意義回憶都有顯著幫助，而沒有一對一中文對應的詞保留較零碎但更持久 ([日本語教育 191](https://www.nkg.or.jp/gakkaishi/.assets/191_04abstract.pdf))。**【缺口】** 松下的逐詞資料庫（www17408ui.sakura.ne.jp/tatsum/）本次無法連線，六類對應關係的細節與授權未取得；也沒有找到特定假朋友（勉強、手紙、大丈夫、娘）的學習者錯誤率統計。

**讀音才是瓶頸：漢語詞用聽的比用看的難。** 松下預測「L1が中国語であれば、『読む・書く』の語彙力が『聞く・話す』の語彙力よりも高く出る」（華語母語者讀寫詞彙量高於聽說），非漢字圈則相反，所以把測驗命名為「閱讀用」詞彙量測驗 ([松下 2018](https://www2.ninjal.ac.jp/jll/lsaj/wp-content/uploads/2015/07/869b469213df7c0f6deaad728b97a6b9.pdf))。佐藤等 2020 用學術共通語彙測驗的音聲版與文字版測華語與韓語母語者，兩組都是文字版較高，但 **華語母語者的差距更大** ([松下 2021 引用](https://repository.ninjal.ac.jp/record/2000019/files/Matsushita2021_kanji-vocab-learning.pdf))。彭悅・梁震・笹尾洋介以 118 名華語學習者驗證音聲版詞彙量測驗，發現「漢語については文字提示よりも音声提示の方が難しい一方で、和語・外来語は音声提示の方が易しくなる」（漢語用聽的比用看的難，和語與外來語反而用聽的較易），且聽覺呈現下三種語種難度無顯著差異，作者建議「以聽覺詞彙為焦點的學習」 ([日本語教育 185](https://www.nkg.or.jp/gakkaishi/.assets/185_7abstract.pdf))。漢字轉換測驗（假名＋語境→選漢字）與詞彙量測驗相關 r = .82，而且 KCT 受 L1 影響較小——用假名出題可以中和華語讀者的字形捷徑 ([松下 2021](https://repository.ninjal.ac.jp/record/2000019/files/Matsushita2021_kanji-vocab-learning.pdf))。松下的明確建議是「漢字語の音声インプットを教師も学習者もより意識して、音声と文字の語彙知識をスパイラルで高めていく」（更重視漢字詞的語音輸入，螺旋式提升語音與文字詞彙知識），並提議以漢字意象連結音讀與訓讀（上昇・昇進 ⇄ のぼる），否則每個音讀詞都要單獨背、數量會爆炸 ([松下 2021](https://repository.ninjal.ac.jp/record/2000019/files/Matsushita2021_kanji-vocab-learning.pdf))。**【缺口】** 沒有研究直接量測「知道意思但唸不出來」的漢字詞比例；玉岡賀津雄的華語學習者論文本次未取得。

**和語與外來語相對最難，片假名詞兩個月掉兩成。** Rasch 分析顯示「中国語L1には『相対的に』漢語は易しく外来語は難しい」（對華語母語者，相對而言漢語易、外來語難），韓語與其他母語者外來語易，日語母語者和語易 ([松下 2021](https://repository.ninjal.ac.jp/record/2000019/files/Matsushita2021_kanji-vocab-learning.pdf))。陣内 2008 對 479 名學習者（49.7% 華語者）的調查：**90% 的華語者** 在日常生活中因片假名詞困擾（韓語者不到 70%），華語者的主要困難是「意味推測不能」64.1%、「発音の違い」60.5%、「辞書不掲載」55.6%、「表記の困難さ」52.5% ([望月 2012 引用](https://kansai-u.repo.nii.ac.jp/record/10178/files/KU-1100-20120300-01.pdf))。望月 2012 歸納片假名詞難在發音擠壓（cut→カット）、表記搖擺（メール／メイル）、意義偏移、**和製英語**（スマート、ナイター）、短縮語（コンビニ）、混種語、動詞化（サボる）、和語漢語外來語近義（ケース／場合）；其課程對 300 個學術片假名詞的測驗平均從立即 80.0 掉到 **兩個月後 60.4**（SD 16.2），「定着率が低く、ばらつきが大きい」 ([望月 2012](https://kansai-u.repo.nii.ac.jp/record/10178/files/KU-1100-20120300-01.pdf))。一位華語學習者的自述具體指出痛點：「ヨーロッパ」花最久，因為小「ッ」與長音最不擅長，而知道英語發音的詞就容易。英語幫助有限：松下判斷「英語L1知識は活用できるが、英語L2知識のプラスは少ない」（英語母語知識可用，英語作為第二語言的加分很少）——**【作者判斷，待驗證】** ([松下 2021](https://repository.ninjal.ac.jp/record/2000019/files/Matsushita2021_kanji-vocab-learning.pdf))。**【原文未取得】** 一項研究稱無日語學習經驗的華語者約能從中文知識猜對三成 **和製漢語**。體裁也重要：學術詞彙七成以上是漢語，文藝詞彙七成以上是和語 ([松下 2018](https://www2.ninjal.ac.jp/jll/lsaj/wp-content/uploads/2015/07/869b469213df7c0f6deaad728b97a6b9.pdf))——台灣使用者若目標是閱讀文學或日常對話，和語的比重會比學術閱讀高得多。

**音調：華語者聽得出來，但促音與長音做不準。** Wiener & Goss 2019 的六組實驗顯示「沒有日語經驗的華語母語者以近乎母語的能力辨別音調；學過日語的華語母語者辨別準確度顯著高於日語母語者」，敏感度隨「音高在所有已知語言中的訊息量」累加 ([Wiener & Goss 2019](https://www.cambridge.org/core/journals/studies-in-second-language-acquisition/article/second-and-third-language-learners-sensitivity-to-japanese-pitch-accent-is-additive/DD55DD75A260E90EBC312A93C4ADDEBE))。線索加權不同：Liu 的研究發現日語者利用 F0 下降斜率與促音造成的 F0 中斷，華語學習者則「重新利用對上升斜率的 L1 敏感度」 ([Sophia Linguistica](https://dept.sophia.ac.jp/is/solific/en/?p=3231))。**【未驗證】** 鮎澤孝子團隊的東京音調聽辨測驗據稱顯示華語者優於韓語者，但原始 PDF 回傳 404。特殊拍是持續問題：洪心怡 2015 對台灣初學者的聲學測量顯示他們 **能** 區分促音／非促音與長音／短音並產生不同時長，「但尚未達到日語促音、長音該有的拍長時間」，且對促音與長音用同一套時長策略，「初級日語學習者仍然將日語的拍當作音節在發音」 ([台灣日語教育學報 24](https://www.taiwanjapanese.url.tw/GAKUHO/24.files/No24-B02.pdf))。戸田貴子的系列研究歸納兩種錯誤：刪除（切って→切て）與插入（来て→来って），有效教學需先診斷錯誤來自音韻知識、聽辨還是構音 ([JPF 日本語教育通信](https://www.jpf.go.jp/j/project/japanese/teach/tsushin/research/031.html))。**【缺口】** 未取得台灣聽者對平板／頭高／中高／尾高各型的準確率；沒有研究探討台語聲調是否改變此圖像。

**文字呈現：提示面絕不給振假名。** Palmer 2012 的放聲思考研究顯示有振假名的組對未知漢字詞的推論更正確 ([Palmer 2012](https://scholarsarchive.byu.edu/etd/3235))，但松下 2021 把「ふりがなは漢字の読みの付随的語彙学習にどの程度効果的なのか」（振假名對讀音附帶學習有多有效、該給哪個程度多少振假名）列為 **尚未解決的研究問題** ([松下 2021](https://repository.ninjal.ac.jp/record/2000019/files/Matsushita2021_kanji-vocab-learning.pdf))。**【未驗證】** 一則搜尋摘要稱振假名對漢字圈學習者的漢字辨識影響不大、對非漢字圈學習者則活化音韻路徑，但未能鎖定出處。對華語使用者的推論非常直接：漢字提示已經透過中文給出意思，若再加振假名，等於把唯一需要提取的東西（讀音）直接送出。另外，高頻但漢字罕見的詞（駄目、奴、嘘、即ち、是非）實際上以假名書寫，「理解さえできれば書く際にはひらがなやカタカナで済む」 ([松下 2021](https://repository.ninjal.ac.jp/record/2000019/files/Matsushita2021_kanji-vocab-learning.pdf))，應以假名為標準形。漢字覆蓋率數據也值得知道：平假名詞佔 59.7% 詞次，加片假名 63.6%，加前 300 漢字 82.6%，**加前 1,000 漢字 95.1%**（約等於教育漢字），前 2,000 漢字 99.2%；但認得漢字不等於認得詞（秋＋季節→秋季可猜，名＋人→名人不可猜） ([松下 2018](https://www2.ninjal.ac.jp/jll/lsaj/wp-content/uploads/2015/07/869b469213df7c0f6deaad728b97a6b9.pdf))。JLPT 詞數的來源需提醒：松下只確認舊制 3 級約 1,500 詞、2 級約 6,000 詞；坊間 N5≈800、N3≈3,750、N1≈10,000 的數字無官方出處，N3 是 2010 年才插入的級別 ([松下 2021](https://repository.ninjal.ac.jp/record/2000019/files/Matsushita2021_kanji-vocab-learning.pdf); [Migaku（二手）](https://migaku.com/blog/japanese/jlpt-vocabulary-lists))。**【自行推算，非發表數字】** 若從 95% 覆蓋所需的 9,446 詞中扣除約 30% 的 S 類同形語，台灣使用者需要「學意思」的有效負荷約 6,500–7,000 詞，但這些詞仍須進「學讀音」佇列。

## 六、建議方案

**資料來源與建置管線。** 以 GitHub Actions 每週排程執行一次建置：下載 jmdict-simplified 最新 `jmdict-eng`（若未來要多語言則用 `jmdict-all`）與 `kanjidic2-en`；接合 Jiten.moe 全域榜（或 Kanjium wikipedia_freq）取得排名，以全部漢字形與假名形接合並取最佳名次（頻率表以表面形為鍵，這是主要工程風險）；接合 OpenJLPT 等級、Kanjium accents.txt（按讀音）、kaikki 中文 Wiktionary 日語／日语兩檔的釋義（經 OpenCC s2twp，無對應時退回英文並標示）、Tatoeba 日中與日英句對（優先用 JMdict_e_examp 的策展子集）；丟棄 sK/sk/rK 形；`uk` 詞以假名為標頭；以 `languageSource` 或純片假名標頭切出外來語類別；輸出每級或每 500 詞一個 JSON（≤ 1–2 MB），每筆帶穩定 id、振假名片段 `[["漢","かん"],...]`、音調數字、語種、同形語類別。同形語 S/O/D/N 標記是唯一沒有現成開放資料的欄位：松下的日中對照資料庫本次無法連線，實務上可先用「JMdict 漢字形是否與 Wiktionary 中文詞條同形」做粗分，再人工標注常用的 O/D 類（趙・上原 2017 列出的 関心、勉強、検討、十分、失敗、娘、湯 等可作種子）。授權上，整個資料層以 CC BY-SA 4.0 公開，每頁頁尾致謝 EDRDG、Tatoeba、Waller/OpenJLPT、Kanjium、Jiten.moe、Wiktionary；若用 VOICEVOX 預產音檔另加「VOICEVOX:角色名」；絕不混入 jpdb、Kanshudo、iKnow Core、NHK2016 轉檔。

**演算法：ts-fsrs（FSRS-6）配預設參數。** 在 open-spaced-repetition 的基準測試（9,999 個牌組、約 3.5 億次複習）中，FSRS-6 的 log loss 為 **0.3460**，遠優於 Duolingo 的半衰期迴歸 HLR（0.4694）與貝氏的 Ebisu v2（0.4989）；神經網路模型雖更好（LSTM 0.3332、RWKV 0.2773）但不適合靜態站 ([srs-benchmark](https://github.com/open-spaced-repetition/srs-benchmark))。**【缺口】** 擷取的 README 片段未含 SM-2／Anki-SM-2 的數字。`ts-fsrs` 5.4.2（2026-10-03 發布、MIT、809 星、最後推送 2026-10-07）以 `fsrs().next(card, now, Rating.Good)` 更新卡片，每卡九個欄位，預設 `request_retention = 0.9`，初始穩定度 w0–w3 為 0.212／1.2931／2.3065／8.2956 天 ([ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs); [constant.ts](https://raw.githubusercontent.com/open-spaced-repetition/ts-fsrs/main/packages/fsrs/src/constant.ts))。建議設定 `{ request_retention: 0.9（可開放 0.80–0.95 滑桿，預設 0.85 亦可辯護）, enable_fuzz: true（避免整批字同一天到期）, enable_short_term: false（單字站不需要當日內學習步驟——這是產品決定，無基準背書）}`。FSRS 選擇的真正理由不只是準確度：它與 Ebisu 一樣提供連續的「此刻可提取率 R」，而 SM-2／Leitner 只有二元的到期與否，連續的 R 正是「幾乎隨機但來自有限集合」所需的加權依據。若日後想做個人化參數最佳化，`fsrs-browser`（WASM）可在瀏覽器內執行 ([fsrs-browser](https://github.com/open-spaced-repetition/fsrs-browser))；想要零依賴則有約百行的 `femto-fsrs` ([femto-fsrs](https://github.com/RickCarlino/femto-fsrs))。HLR 需要以百萬級軌跡訓練 Θ 且無 JS 移植，不適用。

**隨機抽選方式：以遺忘機率加權的無放回抽樣。** Anki 本身就是「排程決定候選集合、隨機決定順序」：新卡收集順序有「隨機」，複習排序有「到期日，然後隨機」 ([Anki manual](https://docs.ankiweb.net/deck-options.html))。有限集合的自然推廣是：每次開始時對池中每個字計算 R（從未見過的字 R = 0），權重 `w = 0.02 + (1 − R)^2`，以 Efraimidis–Spirakis 鍵值（`rand()^(1/w)` 取最大的 K 個）無放回抽 K = 20 字，但從未見過的字上限為每次新字配額（例如 5，由複習預算 ÷ 10 推得），且當逾期字多於 K 時先從逾期子集抽以清掉積壓；抽出後洗牌呈現，每題作答後呼叫 `fsrs().next()` 並持久化。這個設計讓 R = 0.95 的熟字被抽中的機率約為新字的 1/400 但永不排除，每次集合「幾乎隨機」卻追蹤記憶強度，池子沒有到期字時也不會空轉，而且選擇層從不碰 FSRS 內部狀態。對台灣使用者再加一層：和語與外來語的權重乘以 >1 的係數（例如 1.5），S 類同形語的「意思」卡直接不生成、只生成「讀音」卡。**【未測試啟發式】** 指數 2 與下限 0.02 需觀察每次呈現的 R 分布後調整；沒有任何研究比較加權隨機與嚴格到期排序的保留效果。若想要更可預測的 UI，可改用分層配額（新 30%、弱 40%、強 30%，不足時溢給下一層）。

**資料儲存：localStorage 為工作副本，JSON 匯出為通用備份。** 3,000 字 × 約 200 bytes 的 FSRS 狀態約 600 KB，遠低於 localStorage 每來源 5 MiB 的上限；靜態辭典以 `fetch()` 取得、不放進 localStorage，儲存只保留 `{id → card}` 並以穩定 id 而非陣列索引為鍵，資料更新才不會弄壞進度 ([MDN storage quotas](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria))。最大的資料流失風險是 Safari 的 ITP：來源七天內沒有使用者互動時「腳本建立的資料會被刪除」；首次使用時呼叫 `navigator.storage.persist()` 可免於 LRU 驅逐，但 **【未確認】** 是否豁免 ITP 七天規則、以及加入主畫面的 PWA 是否適用。因此必須提供一鍵 JSON 匯出／匯入（`<a download>` 全平台可用；`showSaveFilePicker` 的瀏覽器支援 **【未驗證】**，不可作為唯一路徑）。跨裝置同步在純靜態站只有兩條路：使用者自行貼上僅含 Gist 權限的 fine-grained PAT，網站以 `POST /gists`／`PATCH /gists/{id}` 讀寫（單檔 >1 MB 讀取會截斷） ([GitHub Gists API](https://docs.github.com/en/rest/gists/gists))；真正的 OAuth「無法完全在客戶端實作，因為需要伺服器端持有的 secret」，得加一個 Cloudflare Worker ([Simon Willison](https://til.simonwillison.net/cloudflare/workers-github-oauth))。PAT 只送往 api.github.com、存於使用者自己的瀏覽器，與 GitHub Pages 禁止「處理密碼等敏感資料」的規定相容，但應設為選用並警告 secret gist 仍可由網址存取 ([GitHub Pages limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits))。

**技術堆疊。** 建置用 Vite + TypeScript（Svelte 或 vanilla 皆可，框架不是決定性因素），`base: '/<repo>/'`，以官方 `actions/configure-pages` → `actions/upload-pages-artifact` → `actions/deploy-pages` 工作流部署（權限 `contents: read, pages: write, id-token: write`） ([Vite static deploy](https://vite.dev/guide/static-deploy))；Pages 回應實測有 `Content-Encoding: gzip`、`Cache-Control: max-age=600`，所以幾百 KB 的 JSON 不是問題，但這是觀察而非文件保證。日文顯示必須設 `<html lang="zh-Hant">` 包 UI、`<span lang="ja">` 包每一段日文並以 `:lang(ja) { font-family: "Noto Sans JP", "Hiragino Sans", "Yu Gothic", "Meiryo", system-ui }` 指定字型：W3C 說明同一碼位的表意文字在中日韓語境下字形不同，瀏覽器依內容語言選字型 ([W3C](https://www.w3.org/International/questions/qa-lang-why))——沒有 `lang="ja"` 的 zh-TW Windows 機器會用微軟正黑體的字形顯示 直、骨、海 等字（**【經驗判斷】** 無原始文件）。振假名用 `<ruby><rt>`（2015 年起全瀏覽器支援），標記在建置期產生 ([MDN ruby](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/ruby))；音調以每個拍的 span 加 `border-top` 畫高低線（呈現方式為推論）。假名輸入用 `wanakana`（5.3.1、943 星）：`wanakana.bind(input)` 讓「neko」即時變「ねこ」，比對前雙方都 `toHiragana()` 正規化 ([WanaKana](https://raw.githubusercontent.com/WaniKani/WanaKana/master/README.md))。語音用 `speechSynthesis`：等 `voiceschanged` 事件後過濾 `voice.lang.startsWith('ja')`，行動裝置優先 `localService`，單字單句短語避開 Chrome 桌面約 14 秒的錯誤；Android Chrome「回傳的是語言／地區組合清單而非實際可用語音」且選到未安裝語音會退回英語，所以要試播一次偵測無聲並給 OS 專屬的安裝提示 ([Readium](https://readium.org/speech/docs/WebSpeech.html); [MDN getVoices](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices))。例句切詞用 Baseline 2024 的 `Intl.Segmenter("ja-JP", { granularity: "word" })`，但它不給讀音，振假名仍需建置期資料 ([MDN Intl.Segmenter](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/Segmenter))。可參考的程式碼：`thomasrribeiro/flashcards`（FSRS + Vite + Pages 工作流 + localStorage）、`aszx87410/jpword`（台灣的繁中介面、自動振假名、3,000 字隨機 10 題，無 SRS） ([jpword README](https://raw.githubusercontent.com/aszx87410/jpword/main/README.md))、`obsidian-spaced-repetition` 的演算法文件（乾淨的 SM-2 變體規格）；成熟的日語學習專案（Anki、Yomitan、kanji-koohii）都不是靜態站，主因是需要辭典伺服器或帳號，對單人有限集合的站不是阻礙。**【未逐一確認】** 多數參考倉庫的 LICENSE 欄位在 API 回傳為空，複製程式碼前應個別檢查。

## 結論

把兩條研究線放在一起看，最重要的洞見是：對台灣學習者而言，通用的「單字閃卡」設計有一半是在浪費時間——漢字已經透過中文把前 2 萬詞中三成的意思免費送到眼前，而真正缺的讀音、音調與特殊拍，恰好是選擇題與自評翻卡最測不出來的東西。這使得「打字假名回想」從一個互動選項變成這個使用者群的核心測驗格式，也讓「提示面不給振假名」從排版細節變成學習效果的關鍵；同時，因為同形類義語的錯誤源於自動活化的中文知識，網站需要的不是更多釋義，而是一張明確寫著「中文≠日文」的對比卡，這正是現有教材與現有開放資料都沒有提供的欄位，也是這個專案最值得親手打造的增值部分。

技術上的啟示是，「幾乎隨機」與「間隔重複」的矛盾其實不存在：FSRS 給每個字一個連續的可提取率，只要把隨機抽樣的權重設為「1 − 可提取率」，每次學習看起來隨機、感覺新鮮，實際上卻在系統性地回收即將遺忘的字，而有限池與頻率分帶讓 93%／95% 覆蓋率成為可量化的終點。資料層最大的未解問題不是技術而是授權與覆蓋：中文釋義只能靠繁簡混雜的 Wiktionary 抽取，同形語分類沒有可下載的開放資料，音檔沒有任何詞級開放集。這三個缺口決定了專案的優先順序——先用英文釋義與 TTS 把學習迴圈跑起來，再逐步以 Wiktionary 接合與人工標注補齊中文與同形語欄位，而不是等資料完美才開工。
